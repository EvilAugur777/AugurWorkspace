# Augur Workspace

**Augur Workspace** — это лёгкое портативное рабочее пространство для Windows на базе C# (.NET 8) и `WebView2`, объединяющее изолированные профили, веб-вкладки и запуск локальных программ в одном окне.

Создано для удобной организации рабочих инструментов, локальных веб-сервисов и игровых вкладок (например, торговых поисков с Live Search) без захламления основного браузера и потери фоновой активности.

---

## Основные возможности

* **Изолированные профили в одном окне.** При запуске открывается экран выбора профиля (по умолчанию создаются шаблоны `Work` и `Search`). Переключение между профилями происходит мгновенно через выпадающий список без открытия новых окон. У каждого профиля свои закладки, куки, сессии и кэш.
* **Защита фоновых вкладок от усыпления Windows.** Движок `WebView2` запускается со специальными флагами Chromium (`--disable-features=UseEcoQoSForBackgroundProcess`, `--disable-background-timer-throttling`), благодаря чему Windows не вешает на фоновые вкладки «зелёный листочек» (Efficiency Mode) и не режет таймеры уведомлений.
* **Ленивая загрузка (Lazy Loading) и контроль памяти.** Вкладки создаются только в момент первого клика по ним. При старте программа потребляет минимум ОЗУ даже при наличии десятков закладок. Любую открытую вкладку можно выгрузить из памяти через правый клик мыши.
* **Перехват уведомлений в заголовке.** Если на фоновой вкладке обновляется заголовок с индикатором новых событий (например, `(1)` при срабатывании Live Search), кнопка закладки в боковом меню подсвечивается ярким акцентом и показывает счётчик.
* **Кастомные имена и кнопка «Домой» (`⌂`).** Сайт не перезаписывает название вкладки в меню — вы сами задаёте понятные имена. Кнопка `⌂` справа от закладки мгновенно возвращает открытую страницу к её исходной сохранённой ссылке.
* **Управление ссылками на лету.** В верхней адресной строке есть две кнопки быстрого сохранения:
  * **`☆`** — сохранить текущий адрес как новую закладку сразу под активной.
  * **`💾`** — перезаписать базовую ссылку активной закладки текущим адресом.
* **Запуск локальных программ и файлов.** Помимо веб-ссылок (`http://`, `https://`), в меню можно добавлять пути к `.exe`, `.bat`, `.xlsx`, `.ahk` и любым другим файлам (поддерживается выбор через Проводник).
* **Кэширование иконок сайтов.** Фавиконки автоматически загружаются по домену и сохраняются локально на диск.

## Управление и интерфейс

* **Сворачиваемое боковое меню (`≡`)** — сжимает панель до компактной полосы с иконками.
* **Перетаскивание (Drag-and-Drop)** — порядок закладок в меню меняется простым перетаскиванием мышкой.
* **Контекстное меню (ПКМ):**
  * На карточке профиля: переименование или полное удаление профиля.
  * На закладке: редактирование названия и ссылки, сброс до базовой ссылки, выгрузка из ОЗУ, перемещение и удаление.

---

## Требования для запуска

* **ОС:** Windows 10 или Windows 11 (x64).
* **Среда выполнения:** [Microsoft Edge WebView2 Runtime](https://microsoft.com) (предустановлен в Windows 11 и большинстве современных сборок Windows 10).
* При запуске автономной релизной версии установка `.NET Runtime` не требуется.

## Сборка из исходного кода

Для сборки портативного исполняемого файла со сжатием в один `.exe` выполните в корне репозитория:

```bash
dotnet publish AugurWorkspace/AugurWorkspace.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -p:DebugSymbols=false -o ./Publish
```

Собранный файл появится в директории `./Publish/AugurWorkspace.exe`. При первом запуске программа автоматически создаст папку `Profiles` рядом с исполняемым файлом для хранения настроек и сессий.
